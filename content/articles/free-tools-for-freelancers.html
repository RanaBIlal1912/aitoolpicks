A simple workflow

  1. Create a profile on a freelance marketplace and write a clear service description.
  2. Use an AI assistant to draft proposals, then personalise each one.
  3. Use Canva for a portfolio and Notion to track clients and deadlines.
  4. Run every message through a grammar checker before sending.

A zero-cost setup in one afternoon

  1. Choose one service. Write one sentence: "I help [type of client] with [result]."
  2. Make three samples. Use a design tool to build them, or write them in a document. See how to build a free portfolio website.
  3. Create a tracker. One table with client, job, price, deadline and status is enough.
  4. Save two templates. A proposal and a follow-up message you can personalise each time.
  5. Set up proofreading. Install a free proofreading extension so every message gets a final check.

When it is worth paying

  • A paid feature saves you clear time on work you are already getting paid for.
  • You hit a limit more than once in the same week.
  • A client asks for something the free plan cannot do, such as specific file formats.

If you cannot name the feature you would pay for, stay on the free plan.

Common mistakes

  • Spending a week choosing tools instead of contacting clients.
  • Keeping client details in five different places.
  • Using an AI assistant for client work without checking the output.
