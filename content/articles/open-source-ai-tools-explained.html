"Open" is used loosely in AI. Open source means the code is under a licence that allows use, study and sharing. Source-available means you can read the code but the licence limits use. Open weights means a model's trained parameters are published, often under their own licence. Check which one you are getting.

How this guide was made: it is a documentation-based overview. We read each vendor's official pages and recorded plans, prices and limits on the date shown; we have not run hands-on tests or benchmarks, so nothing here is a performance claim. Prices change, so confirm on the official page before you pay.

How we label licences

On this site a tool is called open source only when its official repository lists an open-source licence. The licences below were read from the repositories on 30 October 2026: Ollama, llama.cpp, LangChain, LangGraph and Whisper are MIT, and vLLM is Apache-2.0. n8n is shown as source-available because its repository says fair-code, not open source.

The tools, side by side

Run models locally

Ollama

Ollama is a tool for running large language models on your own hardware, with optional paid plans for cloud-hosted models. Its source code is published on GitHub under the MIT licence.

Good for: developers, teams. Watch out for: Cloud models are hosted primarily in the United States, with possible routing to Europe.

Plans (pricing verified, checked 30 Oct 2026): Pay as you go: free; Pro: $20/month monthly, $16.67/month billed yearly; Max: $100/month; Team (early access): $500/month; Enterprise: custom pricing.

Inference in C/C++

llama.cpp

llama.cpp is LLM inference in C/C++. Open-source software; the repository lists the licence as MIT.

Good for: developers, hobbyists. Watch out for: You run and maintain it yourself, so hosting, hardware and support costs are your own.

Plans (pricing verified, checked 30 Oct 2026): Self-hosted (open source): free.

Free software is not free to run

The software licence is free, but hardware, hosting, updates and security are yours. For a model that is open-weight rather than open source, read its licence for commercial limits before building a product on it.
